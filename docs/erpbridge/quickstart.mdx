# Quickstart

Get ERPBridge running locally in a few minutes.

## Prerequisites

- Docker (recommended) or a local Go toolchain (Go 1.26+)
- A GitHub account for MCP clients like Claude Desktop or Cursor

## 1. Start the stack

<Tabs groupId="install">
  <TabItem value="docker" label="Docker (recommended)">

```bash title="Start the full stack"
git clone https://github.com/nmdra/ERPBridge.git
cd ERPBridge
docker compose up -d
```

  </TabItem>
  <TabItem value="go" label="Go toolchain">

```bash title="Build and run from source"
git clone https://github.com/nmdra/ERPBridge.git
cd ERPBridge
make build
./erpbridge-server
```

  </TabItem>
</Tabs>

This starts:

- `erpbridge-server` on port `8080`
- `mock-erp` (mock ERPNext) on port `8081`

:::info Redis is optional
The exact-match cache needs Redis. Without it the server still runs — only the cache endpoints return `503`. See [Caching](./caching.mdx).
:::

## 2. Verify the server is healthy

```bash title="Health check"
curl http://localhost:8080/mcp/health
```

Expected response:

```json title="Response"
{"status":"ok"}
```

## 3. Connect an MCP client

<Tabs groupId="connect">
  <TabItem value="http" label="Streamable HTTP (Postman, remote clients)">

Base URL:

```
http://localhost:8080/mcp/
```

See the [Connectivity & Transport Guide](./connectivity.mdx) for the full handshake and Postman setup.

  </TabItem>
  <TabItem value="stdio" label="Stdio (Claude Desktop, Cursor)">

Run the server binary in stdio mode:

```bash title="Stdio transport"
erpbridge-server --stdio
```

  </TabItem>
</Tabs>

## 4. Discover tools

Request the tool list through the MCP `initialize` and `tools/list` lifecycle, or use the CLI:

```bash title="List registered tools"
./bridgectl tool get
```

:::tip Need the CLI?
The complete `bridgectl` reference lives in its own section — see the [Bridgectl overview](../bridgectl/overview.mdx).
:::

## 5. Call a tool

```bash title="Direct invocation"
curl -X POST http://localhost:8080/api/tools/invoke \
  -H 'Content-Type: application/json' \
  -d '{"name": "erp.list_employees", "arguments": {}}'
```
