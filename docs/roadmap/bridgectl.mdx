# Bridgectl Roadmap

The CLI tool for managing ERPBridge tools, cache, logs, and contexts.

## Shipped

- CLI interface with `api`, `tool`, `cache`, `log`, `context`, and completion commands.

## In flight

- **CLI Hygiene**: Structured JSON log tail filtering, server-side tool filtering, and atomic registry writes.
- **Token Management**: Commands for `token create`, `list`, and `revoke`.
- **API Token Contexts**: Plumbing to inject `api-token` transparently into all server requests.
