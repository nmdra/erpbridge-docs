# Roadmap

This page is the status index for the ERPBridge family. Use it to distinguish capabilities that are shipped today from work that is actively being hardened and ideas that are still future direction.

:::note Status labels

- **Shipped** means the capability is available in the current documentation release.
- **In flight** means work is active but may change before release.
- **Future** means the direction is recorded, not a delivery commitment.

:::

## Release lines

ERPBridge Server and `bridgectl` are released together. The SDK uses its own package version so client updates can ship independently.

| Product | Current release | Release source |

## Where to start

- **Evaluating ERPBridge:** run the [Server Quickstart](../erpbridge/quickstart.mdx).
- **Connecting an ERP:** follow the [Onboarding Guide](../erpbridge/onboarding.mdx).
- **Automating operations:** read [bridgectl Skill Usage](../bridgectl/skills.mdx).

## Influence the roadmap

- Report bugs and request features in [GitHub Issues](https://github.com/nmdra/ERPBridge/issues).
- Review release changes in the [ERPBridge changelog](https://github.com/nmdra/ERPBridge/blob/main/CHANGELOG.md).
- Use the project milestone list on GitHub to see planned sequencing.
