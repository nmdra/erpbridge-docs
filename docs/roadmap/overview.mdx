# Roadmap Overview

The ERPBridge project family connects legacy ERP systems to AI-based workflows without changing the ERP code base. This section outlines the current focus and future plans across the different parts of the project:

- [Server](server)
- [Bridgectl](bridgectl)
- [SDK](sdk)

## How to influence the roadmap

- Report bugs and request features in [GitHub Issues](https://github.com/nmdra/ERPBridge/issues)
- Check [CHANGELOG.md](https://github.com/nmdra/ERPBridge/blob/main/CHANGELOG.md) for the latest release notes
- The milestone list on GitHub tracks what lands next

## Adding a new project

Create a new section under `docs/<project>/` and register it in `sidebars.ts` and the navbar in `docusaurus.config.ts`.
