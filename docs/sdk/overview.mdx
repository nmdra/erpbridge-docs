# ERPBridge SDK

The `@erpbridge/sdk` TypeScript client library lets you integrate ERPBridge into your Agentic AI workflow applications. It is the easiest way to embed the bridge in your own products: call MCP tools by exact name, invoke tools over REST, aggregate logs, read metrics, check health, and manage the cache and tool registry — all through one typed facade.

## Features

- **Built-in MCP client** for the ERPBridge server — connect, discover, and call tools programmatically
- **Exact-name tool proxy** — call registered tools such as `list_employees` directly, with argument validation against each tool's input schema
- **Log aggregation** — collect and inspect bridge logs from your application
- **View metrics** — read Prometheus metrics from the server, raw or parsed
- **Health and cache** — server health checks and cache statistics or flushing
- **Tool registry and direct invoke** — manage registered tools over REST and call them without an MCP session
- **Typed errors** — a single `ErpbridgeError` hierarchy across the whole surface
- **Consume-only authentication** — send administrator-provisioned bearer tokens with per-surface routing
- **Dual build** — ESM + CJS, Node.js >= 20, dependency-light
- **Browser MCP/tools** — use the ESM MCP client and exact-name tool proxy in
  browser bundles when the server's `/mcp/` CORS policy is configured

## Status

:::info Current SDK release

`@erpbridge/sdk` is currently **v1.0.0**, released independently from the ERPBridge Server and `bridgectl` version line. It ships the MCP client, exact-name tool proxy, logs, metrics, health, cache, tool registry, direct invoke, and consume-only authentication. See the [SDK CHANGELOG](https://github.com/nmdra/erpbridge-sdk/blob/main/CHANGELOG.md) for release details.

:::

## Package

`@erpbridge/sdk` is published on [npm](https://www.npmjs.com/package/@erpbridge/sdk) with signed provenance (SLSA), dual ESM + CJS builds, and TypeScript declarations for both. Install it from the [installation](./installation.mdx) page.

## Repository

The SDK is developed in the [erpbridge-sdk](https://github.com/nmdra/erpbridge-sdk) repository. Its operating manual for AI agents and contributors — plan-first workflow, TDD, quality gates, release pipeline, and code conventions — lives in the [Agent Guide](./agent-guide.mdx).
