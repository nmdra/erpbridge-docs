# ERPBridge SDK

The SDK lets you integrate ERPBridge into your Agentic AI workflow applications without the hassle. It is the easiest way to embed the bridge in your own products.

## Features

- **Built-in MCP client** for the ERPBridge server — connect, discover, and call tools programmatically
- **Exact-name tool proxy** — call registered tools such as `list_employees` directly, with argument validation
- **Log aggregation** — collect and inspect bridge logs from your application
- **View metrics** — read Prometheus metrics from the server
- **Health and cache** — server health checks and cache statistics or flushing
- **Tool registry and direct invoke** — manage registered tools over REST and call them without an MCP session

## Quickstart

```ts
import { createClient } from '@erpbridge/sdk'

const client = createClient({ baseUrl: 'http://localhost:8080' })

await client.mcp.connect()
const result = await client.tools.list_employees({ department: 'engineering' })
console.log(result.result)
```

Errors are typed across the whole surface (`ErpbridgeError` and subclasses:
`AuthenticationError`, `NotFoundError`, `RateLimitError`, `ServerError`,
`ProtocolError`). See the package README for the full guide.
